# --- orchestration ---------------------------------------------------------

# checkpointed threads that span weeks, and interrupt(), which IS the consent
# gate (docs/ARCHITECTURE.md §11.4).

langgraph-checkpoint-sqlite>=2.0
langchain-core>=0.3

# --- models ----------------------------------------------------------------
# The local development / iteration tier. Bedrock lives in the aws extra below.
langchain-groq>=1.1

# --- schemas ---------------------------------------------------------------
# Every agent output is a pydantic model. Schema validation pass rate is a
# graded metric; it is only measurable because these exist.

# Every external capability is an MCP server. These are real servers:
# `uv run -m src.mcp.overlap` speaks MCP over stdio.

# One trace per encounter and per continuity action. The trace is the
# debugging tool, the explainability source, and the demo.
